# Флора·Учёт

Бот-бухгалтер для цветочного ларька: Telegram-бот + Mini App + Google Таблица (этап 1, 0 ₸ в месяц).

## С чего начать
- Правила проекта — `CLAUDE.md` (Claude Code читает его сам).
- Что делаем сейчас — `docs/PLAN.md`.
- Проверка расчётов: `npm test` (должно быть `fail 0`).

## Документы
| Файл | Зачем |
| --- | --- |
| `docs/TZ.md` | Полное ТЗ |
| `docs/DECISIONS.md` | Решения, уточняющие ТЗ (при расхождении действуют они) |
| `docs/ARCHITECTURE.md` | Как устроено внутри, подводные камни |
| `docs/DATA_MODEL.md` | Листы таблицы и колонки |
| `docs/PLAN.md` | План по этапам A–G |
| `docs/BACKLOG.md` | Отдельные задачи (визуал, договор) |
| `docs/GOLDEN_TEST.md` + `tests/golden_shift.json` | Эталонная смена — цифры до тенге |
| `docs/DESIGN.md` + `design/` | Текущий дизайн и макеты |
| `docs/LINKS.md` | Ссылки на документы и документацию |

## Важно
- Токен бота никогда не вставлять в чат и в файлы — только в Script Properties.
- Бот не заменяет онлайн-кассу: чеки ККМ пробиваются как раньше.
