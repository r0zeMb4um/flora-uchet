# Флора·Учёт — стартовый пакет для Claude Code

Бот-бухгалтер для цветочного ларька: Telegram-бот + Mini App + Google Таблица (этап 1, 0 ₸ в месяц).

## Как начать
1. Распакуйте архив, например в `Документы/flora-uchet`.
2. Откройте терминал в этой папке и запустите `claude`.
3. Вставьте текст из `prompts/01-start.md`.
4. Дальше идите по `docs/PLAN.md` — по одному шагу за раз.

## Что в папке
| Файл | Зачем |
| --- | --- |
| `CLAUDE.md` | Правила проекта для Claude Code (он читает его сам при каждом запуске) |
| `docs/TZ.md` | Полное ТЗ |
| `docs/PLAN.md` | План разработки по шагам с проверками |
| `docs/DATA_MODEL.md` | Листы таблицы и колонки |
| `docs/GOLDEN_TEST.md` + `tests/golden_shift.json` | Эталонная смена — цифры, которые должны сойтись до тенге |
| `docs/DESIGN.md` + `design/` | Цвета, шрифт и макеты 8 экранов |
| `docs/LINKS.md` | Ссылки на документы проекта и документацию |
| `prompts/01-start.md` | Первый промпт и следующие шаги |

## Важно
- Токен бота из BotFather никогда не вставляйте в чат и в файлы — Claude Code подскажет, куда его положить (Script Properties).
- Бот не заменяет онлайн-кассу: чеки ККМ магазин пробивает как раньше.
