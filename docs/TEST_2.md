# Тест №2: начинаем с чистого листа

Цель: пройти путь «запуск магазина → первая смена → закрытие» на чистых данных, так как это будет у владелицы.

## Шаг 0. Чистка тестовых данных (делает администратор, ~5 минут)
1. script.google.com → проект «Флора·Учёт — пилот» → файл `admin.gs`.
2. Выбрать функцию `resetTestData` → «Выполнить». В журнале будет список «Будет очищено» (строки по листам) и фраза «Пока ничего не удалено».
3. Проверить цифры. Если всё верно: в начале функции поменять `var CONFIRM = false;` на `true`, сохранить, «Выполнить» ещё раз.
4. В журнале должно появиться «Копия до чистки: …» (ссылка на копию на Диске) и «ГОТОВО». Копию оставьте на неделю.
5. Затем один раз запустить `installTriggers` (в `maintenance.gs`): появится «прогрев» кассы раз в 5 минут.

Остаётся: владелица, настройки, клиент и точка. Флористы удалены: приглашаете заново.

## Шаг 1. Владелица заходит и настраивает
- [ ] Закрыть кассу целиком и открыть заново. Внизу вкладки: Сегодня · История · Сводка · Склад · Ещё.
- [ ] «Ещё» → «Настройки»: размен и время напоминания.
- [ ] «Ещё» → «Сотрудники» → «Добавить флориста»: имя, ставка, процент. Отправить ссылку флористу.

## Шаг 2. Каталог и остатки (вкладка «Склад» → «Добавить»)
- [ ] «Выбрать из типовых»: отметить, что есть в магазине. Нажать «Добавить выбранные».
- [ ] В таблице вписать цену и остаток (закупку можно пропустить). «+ Цветы», «+ Зелень» и др. добавляют свою строку.
- [ ] Закрыть кассу и открыть: черновик на месте.
- [ ] «Сохранить N позиций». На вкладке «Склад» → «Список» цифры совпали с пересчётом.

## Шаг 3. Первая смена
- [ ] Флорист открывает кассу: «Открыть смену», «Первая смена магазина», вписывает наличные. Сообщения о расхождении нет.
- [ ] Продажи: наличные, карта, смешанная, в долг; быстрая продажа; чек картинкой.
- [ ] «Склад» → «Принять товар» (или «+» у позиции); «Списать брак».
- [ ] «Ещё» → «Расход», «Возврат», «Отмена продажи».
- [ ] Владелица: «Сегодня» показывает смену; «Ещё» → «Расходы месяца»: аренда, интернет, налоги разом.
- [ ] Закрытие смены: инвентаризация, пересчёт вслепую, итог. Владелица получает отчёт с блоком «Контроль».

## Шаг 4. Скорость
- [ ] Переключение вкладок владелицы: открывается сразу (данные сначала из памяти, потом обновляются).
- [ ] Первое открытие кассы утром (после паузы) не дольше 5–7 секунд, последующие быстрее.
- [ ] Если телефон слабый и тормозит: «Ещё» → «Включить лёгкий вид».
