# Чек-лист сквозной проверки перед пилотом

Проходить на телефоне. Отмечайте ✅ или пишите, что не так. Деньги тестовые: после проверки смену закройте, тестовые данные потом можно обезличить.

## 0. Подготовка (5 минут)
- [ ] Закрыть Mini App целиком и открыть заново (чтобы подтянулась новая версия).
- [ ] У флориста и у владелицы в чате с ботом набрать `/start`: старые кнопки должны замениться одной «Открыть кассу».
- [ ] В свойствах скрипта есть `ADMIN_TELEGRAM_ID`; `installTriggers` выполнен; в папке «Флора·Учёт — резервные копии» есть копия.

## 1. Владелица: настройка магазина
- [ ] «Управление» → «Настройки»: размен и время напоминания сохраняются.
- [ ] «Управление» → «Склад и каталог»: поменять цену одной позиции, сохранить; скрыть позицию и вернуть; добавить новую («Пион розовый»).
- [ ] «Управление» → «Сотрудники» → «Добавить флориста»: ввести имя, ставку, процент (например 2,5). Получить ссылку, нажать «Отправить в Telegram».
- [ ] Клавиатура при вводе не закрывается ни в одном поле.

## 1а. Запуск без тетради (владелица)
- [ ] «Управление» → «Склад и каталог» → «Загрузить списком»: вставить список по категориям (название; цена; остаток; закупка; минимум). Закупку можно не знать.
- [ ] Остатки вносятся, когда смена закрыта. Проверить на «Складе»: цифры совпали с пересчётом.
- [ ] Если нужно: «Начальные остатки» для позиций, добавленных без остатка; «Долги с прошлого» (на первый запуск не требуются).
- [ ] Первая смена: флорист вносит наличные в кассе. Сообщения о «расхождении» быть не должно.

## 2. Флорист: вход и смена
- [ ] Открыть ссылку-приглашение с телефона флориста, пройти согласие. Появляется «Касса».
- [ ] Главная: «Открыть смену». Видно «Прошлая смена оставила N ₸». Ввести другую сумму: появляется расхождение; владелица получает сообщение.
- [ ] Выбрать «Только я» или напарника. Смена открылась.
- [ ] Приход: внести товар по накладной. Остаток на «Складе» вырос.

## 2а. График и смена владелицы
- [ ] Владелица: «Управление» → «График смен»: поставить на несколько дней себя и флориста. У флориста на главной «Ваша ближайшая смена», в «Ещё» → «График смен» виден месяц.
- [ ] Владелица нажимает «Я в смене» вверху: выбирает «Без оплаты» (или ставку и процент). Открывает смену с напарником, продаёт, закрывает. Кнопка вверху возвращает в «Кабинет».
- [ ] Процент напарника при «Без оплаты» не делится пополам.

## 3. Флорист: продажи
- [ ] Быстрая продажа (плитки «Частые», «Повторить последнюю»), оплата наличными. Экран «Принято», чек картинкой приходит в чат.
- [ ] Продажа с оплатой картой и смешанная.
- [ ] Продажа в долг новому покупателю.
- [ ] Продажа по заниженной цене и со скидкой: проходит, но попадёт в «Контроль».
- [ ] Попытка продать больше остатка: понятная ошибка у поля и кнопка «Внести приход».
- [ ] Без интернета (режим «В самолёте»): продажа ставится в очередь, вверху полоска «Нет связи». Включить связь: продажа уходит сама.

## 4. Предзаказы
- [ ] Предзаказ на 3 000 ₸ с авансом 1 000 ₸.
- [ ] Сборка из состава дороже заказа (например 40 роз): отказ «Состав на 48 000 ₸, заказ на 3 000 ₸».
- [ ] Сборка в пределах суммы заказа проходит; выдача с доплатой; выдача с остатком в долг.
- [ ] Владелица: «Управление» → «Предзаказы» → отмена другого предзаказа с возвратом аванса и возвратом цветов на склад.

## 5. Флорист: «Ещё»
- [ ] Расход (доставка 500 ₸): виден в «Контроле».
- [ ] Возврат денег по чеку: владелице приходит сообщение сразу.
- [ ] Брак на сумму от 5 000 ₸ по закупке: владелице приходит сообщение сразу.
- [ ] Отмена продажи (причина обязательна): остаток вернулся, владелица получила сообщение.
- [ ] Погашение долга: больше долга принять нельзя.
- [ ] «Владелица забрала из кассы»: владелица получает сообщение.
- [ ] «Назад» с этих экранов ведёт в «Ещё».

## 6. Закрытие смены
- [ ] Инвентаризация → расходы → пересчёт вслепую (расчётной суммы до ввода не видно) → итог.
- [ ] Если наличных не хватает на ЗП: выдано сколько есть, остальное «ЗП к доплате» в отчёте.
- [ ] Владелица получила отчёт в чате: цифры сходятся, есть блок «Контроль» (цена ниже каталога, скидки, возвраты, брак, расходы, долги).
- [ ] Закрыть смену с неотправленной очередью нельзя (сообщение).

## 7. Владелица: отчёты
- [ ] «Сегодня»: вчера, карточка дня картинкой, закупка на неделю.
- [ ] «История»: открыть смену, чеки; исправить чек закрытой смены.
- [ ] «Сводка»: график, прибыль с подписью, «Выгрузить в Excel» (файл приходит в чат; если нет, придут два CSV).
- [ ] «Должники»: список и итог.
- [ ] «Управление» → «Расходы месяца»: вписать аренду, интернет и налоги в соседние поля и записать одной кнопкой; исправить минусом; прибыль в сводке учитывает.
- [ ] Доплата ЗП: нельзя больше, чем «к доплате».

## 8. Защита и надёжность
- [ ] Флорист не видит разделов владелицы.
- [ ] Отключить флориста («Сотрудники» → «Отключить доступ»): касса у него закрывается сразу; вернуть доступ.
- [ ] Двойное нажатие «Провести»: одна продажа, не две.
- [ ] Бот здоров: `…/exec?health=1` показывает `connected: true`, `stock_matches_journal: true`.

## 9. До первых реальных денег
- [ ] Юрист посмотрел согласие и договор (пункт про технический доступ администратора, D16).
- [ ] Владелица подтвердила решения «по умолчанию» (D4–D7, D9, D11–D13, D20–D24, D26).
- [ ] Проверено восстановление из копии (раздел «Восстановление из копии» в RUNBOOK).
