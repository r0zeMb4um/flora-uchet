# План разработки (этап 1: Google Таблица + Apps Script + Mini App)

Отмечай выполненное: `- [x]`. Каждый этап заканчивается проверкой, которую владелец проекта может сделать сам.

## B. Симуляция смены (без Google)
- [ ] `apps-script/core/ops.js`: каждая операция → проверка → план записи (строки по листам, изменения остатков и статусов). Операции: открыть смену, продажа, букет, предзаказ, бронь, сборка, выдача, приход, брак/подарок, возврат (деньги/замена), отмена продажи, погашение долга, стартовый долг, стартовый остаток, расход, изъятие, инвентаризация, закрытие смены.
- [ ] «Таблица в памяти» и `tests/shift.sim.test.js`: эталонная смена целиком через операции; повтор с тем же `op_id` не задваивает; обрыв после `pending` дописывается; отказы (больше остатка, оплаты ≠ итого, итого = 0, смена не открыта, вторая смена при открытой, возврат больше оплаченного, выдача предзаказа с непокрытым остатком); зависшая операция → `failed` и пересчёт остатков; расходы месяца владелицы не попадают в кассу смены; долги по `debt_moves` (Айгуль 4 500, Ерлан 0).

**Проверка:** `npm test` зелёный; отчёт смены из симуляции совпадает с эталоном.
