# Отдельные задачи (разбираем по порядку)

## 1. Визуал Mini App — переработка
Статус: ждёт обсуждения. До него Mini App верстается по `docs/DESIGN.md` и макетам в `design/`.

Что разобрать:
- [ ] Тёмная тема: своя тёмная палитра токенов, переключение по теме Telegram (фирменные primary и copper сохраняются).
- [ ] Недостающие экраны флориста: предзаказы и брони, брак, возврат, остатки.
- [ ] Экраны владелицы: сегодня (есть макет), история, сводка, каталог, сотрудники, должники.
- [ ] Состояния: загрузка («Проводим…»), нет интернета, отказ («нет на складе»), «уже проведено», пустые списки.
- [ ] Перенос стилей из макетов в общий файл (`miniapp/css/`), набор компонентов: плитка позиции, карточка суммы, цифровая клавиатура, чипы, строка «расчёт/факт».
- [ ] Штатные элементы Telegram: MainButton, BackButton, вибрация.

## 2. Ответы владелицы магазина
Решения «по умолчанию» из `docs/DECISIONS.md` (D4–D7, D9) и раздел «Решения по умолчанию» ТЗ — подтвердить на этапе F.
